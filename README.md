# Zeny1303 — Portfolio

This repository contains my personal portfolio: a small, fast website built with Vite and React that showcases projects, skills, and contact information.

The site is intentionally minimal and focused on performance, accessibility, and clean design. It uses modern front-end tooling for a smooth development experience.

---

## Tech stack

- JavaScript (ESNext)
- Vite
- React
- HTML & CSS
- ESLint

---

## Development

Prerequisites
- Node.js 16+ (Node 18+ recommended)

Quick start

```bash
# install dependencies
npm install

# start dev server with HMR
npm run dev

# build for production
npm run build

# preview production build
npm run preview
```

Scripts in package.json may vary — check `package.json` for the exact commands.

---

## Project structure (high level)

- index.html — app entry
- src/ — React source files
- public/ — static assets
- package.json / package-lock.json — project metadata & dependencies

---

## Customization

- Replace content in `src` to update sections (projects, about, contact).
- Update fonts or styles in `index.html` and the CSS files.
- To change meta information (title, description), edit `index.html`.
