WHAT WAS FIXED
═════════════════════════════════════════════════════════════════════════════════

Issue: Cortex project page (/work/cortex) was not scrollable
       Content below the fold was hidden and unreachable

Root Cause: Global CSS in App.css had:
            - body { height: 100vh; overflow: hidden; }
            - This locked the page to 1 viewport height
            - All content beyond viewport was cut off

Solution: Changed App.css to use min-height instead of fixed height
          Removed overflow: hidden constraint
          Page now scrolls naturally

═════════════════════════════════════════════════════════════════════════════════
CSS CHANGES MADE
═════════════════════════════════════════════════════════════════════════════════

FILE: src/App.css
─────────────────────────────────────────────────────────────────────────────────

BEFORE (❌ Blocked scrolling):
  body {
    height: 100vh;        ← Fixed to 1 viewport
    width: 100vw;         
    overflow: hidden;     ← Blocked ALL scrolling
  }
  
  #root {
    height: 100%;         ← Inherits fixed height
    width: 100%;
  }

AFTER (✅ Allows scrolling):
  body {
    min-height: 100vh;    ← At least 1 viewport, but grows
    width: 100%;
    overflow-x: hidden;   ← Only hides horizontal bar
  }
  
  #root {
    width: 100%;
    min-height: 100vh;    ← Expands to fit content
  }

FILE: src/components/cortex/CortexProjectDetail.css
─────────────────────────────────────────────────────────────────────────────────

BEFORE (❌ Conflicting flex layout):
  .cortex-project-page {
    width: 100%;
    overflow-y: auto;
    display: flex;
    flex-direction: column;
  }

AFTER (✅ Natural flow):
  .cortex-project-page {
    width: 100%;
    overflow-x: hidden;
  }

WHY THIS FIX WORKS
═════════════════════════════════════════════════════════════════════════════════

CSS Box Model Flow:
  
  body (min-height: 100vh)
    ↓ Minimum height is 1 viewport
    ↓ Grows if content needs more space
    ↓
  #root (min-height: 100vh)
    ↓ Fills body, grows as needed
    ↓
  CortexProjectDetailPage
    ↓ Natural block flow
    ↓ Stacks all sections vertically
    ↓
  14 Sections
    ↓ Total height = sum of all sections
    ↓ Exceeds viewport height
    ↓
  Browser scrolling activates
    ↓ Allows scrolling through all content ✅
